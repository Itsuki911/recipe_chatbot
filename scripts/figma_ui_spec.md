# Figma UI Spec

Use this as the Figma handoff for the Streamlit frontend.

## Screen

- Desktop frame: 1440 x 1024
- Left sidebar: 280 px, warm off-white background
- Main chat canvas: centered 860 px max width
- Header: `Recipe Inference RAG Chatbot`
- Modes: Chat, JSON + PostgreSQL, DB DataFrame

## Visual Direction

- ChatGPT/Gemini inspired, but recipe-focused and calm
- Background: soft rice white
- Accent: muted shiso green and soy-sauce brown
- Cards: max 8 px radius
- Message bubbles:
  - User: right-aligned, pale green
  - Assistant: left-aligned, white with subtle border
- Source chips: small rounded pills under assistant answer

## Core Components

- Sidebar navigation
- Chat message list
- Chat input docked at bottom
- JSON generation panel
- DataFrame table view

## Tokens

- Background: `#fbfaf7`
